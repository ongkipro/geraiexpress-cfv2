### Findings

1. **P1 — Unconditional assigned≤observed guard remains in authoritative contracts.**  
   **Locations:** `DECISIONS.md:11`; `PRD.md:61`; contradicted by `docs/spec/02-PRICING-DISCOUNT-AND-CASHBACK.md:51–52`.  
   DEC-230 permits a pending request above observed, but DEC-205 and PR-11 still mandate unconditional rejection. Example: assigned `3000`, observed `2000`, state `Belum diterapkan` is simultaneously permitted and forbidden.  
   **Fix:** amend DEC-205 and PR-11 to the same pending-request exception, explicitly separating requested discount from effective/provider cost. Clarify the no-subsidy explanation in spec 02’s instrument-1 row (`:29`); retaining its provider-cost cap is financially consistent.

2. **P1 — Verification tolerance and state guard contradict each other.**  
   **Location:** `docs/spec/02-PRICING-DISCOUNT-AND-CASHBACK.md:44–52`.  
   Assigned `2000`, observed `1999` must become `Sesuai` under the 1-bp tolerance, yet assigned>observed is permitted **only** in `Belum diterapkan`. Likewise, a previously verified `2000` rule drifting to observed `1000` must become `Selisih`, which the guard makes invalid.  
   **Fix:** define one tolerance-aware guard and explicit pending/verified/drift transitions. Provider observations must remain recordable as `Selisih` without rewriting provider truth or inventing a subsidy. Add both fixtures to TASK-207.

3. **P1 — New verifier uses the regular-service discount field for cargo rules.**  
   **Locations:** `docs/spec/02-PRICING-DISCOUNT-AND-CASHBACK.md:44–46`; `TASKS.md:311–312,378`.  
   These universally compare/store `discountPercent`, while spec 02 `:20` requires cargo to use **only cargo-specific** fields, including `cargoDiscount` and `cargoEstimatedSpecialPrice`. A service response with different regular and cargo discounts can therefore falsely verify—or falsely reject—a cargo rule.  
   **Fix:** define service-class-specific normalization to observed bps; use cargo fields for cargo verification and quote observations. Add a fixture where regular and cargo discounts differ.
