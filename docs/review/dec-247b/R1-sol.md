# Review — DEC-247B Round 1 (`b0af329..d72a5d7`)

## Findings

- **P1 — Dropship tracking exposes the outlet identity and precise pickup pin.** The tracking projection deliberately returns `outletContact: null` when outlet branding is masked (`apps/worker/src/do/gerai-vault/minisite/index.ts:192`, `apps/worker/src/do/gerai-vault/minisite/index.ts:211`). But `trackWa` falls back to the ordinary outlet shell (`apps/worker/src/minisite/index.ts:256`), which now renders the uploaded outlet logo, a Google Maps link with exact coordinates, and the outlet WhatsApp link (`apps/worker/src/minisite/html.ts:130`, `apps/worker/src/minisite/html.ts:156`, `apps/worker/src/minisite/html.ts:163`). ADR-0005 explicitly excludes outlet branding and contact from dropship public tracking (`docs/adr/ADR-0005-three-way-masking-and-return-intake.md:20`). Carry an explicit masking flag into the shell for both the tracking result and the unlock response. Test that a masked result omits the outlet mark, name, map, and chat while ordinary tracking retains them.
- **P1 — A valid outlet name can break every mini-site page.** The initials regex matches Unicode letters, but `w[0]` takes one UTF-16 code unit. A name beginning with a supplementary-plane letter such as `𠮷` leaves a lone surrogate, which makes `encodeURIComponent` throw while rendering the favicon (`apps/worker/src/minisite/html.ts:118`, `apps/worker/src/minisite/html.ts:126`). Profile validation accepts such names (`apps/worker/src/do/gerai-vault/settings/index.ts:36`). Take the first Unicode code point instead and add a worker test that saves such a name and loads the home page.
- **P1 — `/cara-kerja` describes the Non-COD payment flow as universal.** The new pipeline says every shipment goes through all five stops and pays the public shipping tariff at the counter; the new system-role copy also describes a seller-balance debit at issuance without limiting it to Non-COD (`apps/worker/src/brand/pages.ts:517`, `apps/worker/src/brand/pages.ts:534`, `apps/worker/src/brand/pages.ts:568`). COD and DFOD do not collect shipping at the counter, and their provider charges are netted from the credit rather than debited at issue (`packages/domain/src/money/index.ts:267`, `packages/domain/src/money/index.ts:269`, `packages/domain/src/money/index.ts:281`). Keep the five-stop layout, but distinguish the payment paths and qualify when COD settles.
- **P2 — The HTML logo lookup does not enforce the same ownership rule as `/logo`.** `publicShell` matches `id`, purpose, and MIME type but not `m.tenant_id`; a wrong-owner media row present in the tenant object would publish its ID prefix and render a broken logo rather than the monogram. The image route itself rejects such a row, so this is not a cross-tenant image read (`apps/worker/src/do/gerai-vault/minisite/index.ts:33`, `apps/worker/src/do/gerai-vault/minisite/index.ts:49`, `apps/worker/src/minisite/index.ts:315`). Bind the verified tenant ID in the shell join and test a wrong-owner media row, not just a pointer to an ID absent from the object.
- **P2 — Validation ownership is inferred from message text.** If a caller sets its own custom error to the same string the helper last wrote, the next `input`, `change`, or submit click clears the caller's error. The `WeakMap` cannot distinguish identical strings written by different callers (`apps/web-app/src/lib/form-validation-id.ts:94`, `apps/web-app/src/lib/form-validation-id.ts:105`). The current tests cover only different messages (`apps/web-app/src/lib/form-validation-id.test.ts:121`, `e2e/courier-logos.spec.ts:146`). Track ownership when the setter is called rather than comparing the resulting text, and add a same-message regression.
- **P2 — The quote POST silently rewrites malformed dimensions.** Stripping non-digits turns `-20` into `20` and `1.5` into `15` before validating the quote. Three explicit zeroes are treated as no dimensions because the shared parser checks whether any value is positive (`apps/worker/src/minisite/index.ts:114`, `apps/worker/src/pricing/quote/service.ts:30`). Validate the original submitted strings: if any dimension is supplied, require all three to be integers from 1 to 300. Add worker cases for malformed and zero dimensions.
- **P2 — The simulator listboxes miss the mandated 16px mobile type.** The primary option text is explicitly `.9375rem` (15px) on both triggers and options, with no simulator mobile override (`apps/worker/src/brand/styles.ts:9`, `apps/worker/src/brand/styles.ts:175`). The trigger height meets the requirement. Set the simulator’s primary option text to `1rem` at the phone breakpoint and assert the computed size in the mobile test.
- **P2 — The mini-site menu cannot be opened with Space.** The trigger is an anchor exposed as a button; it listens for click, but the only key handler covers Escape (`apps/worker/src/minisite/html.ts:172`, `apps/worker/src/minisite/html.ts:182`, `apps/worker/src/minisite/html.ts:183`). Enter works through native link activation; Space does not. Use a native button with a no-JS fallback, or handle Space on the existing trigger and test it at phone width.
