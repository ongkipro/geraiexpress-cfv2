     1. In `server.mjs:13,17`, `req.on("end", async () => { ... new URL(req.url, "http://relay") ... })` has no `try/catch`.      4. In `verify.mjs:9,54,71`, an unknown flag typo (e.g. `--partner-prod`) falls into the `else` branch, skips steps 3–4, and exits `0` (`RELAY VERIFY PASS`); `fetch` calls (`lines 19,40`) also lack `AbortSignal.timeout`.

     - In `server.mjs`, attach `req.on("error", () => {})` and `res.on("error", () => {})`, extract pathname without authority parsing (`(req.url ?? "/").split("?")[0]`), and wrap the `end` handler in `try/catch` returning `400`/`500` JSON on unexpected errors.

     - In `verify.mjs`, exit `2` when `flag !== undefined && flag !== "--partner-sandbox" && flag !== "--partner-production"`, and wrap `fetch` calls with `AbortSignal.timeout(15_000)` and `try/catch`.

3. **[P2] Operator checks miss daily email bounce alerts (`E_DELIVERY_FAILED` bounces count as `0 %` failure), re-page forever on dormant 5-fail streaks while masking `issue_reconciliation_rate`, ignore connected tenants whose finance sync never ran, and permanently blind active tenants past UUID rank 200**

     2. **Unbounded `failedStreak` & masked `issue_reconciliation_rate` (`do/gerai-vault/index.ts:2199,2210`, `checks.ts:30-38`):** `recentStates` queries `ORDER BY created_at DESC LIMIT 5` with no recency filter.
