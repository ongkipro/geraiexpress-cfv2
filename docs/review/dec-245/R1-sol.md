## Correct

- **Apex host isolation:** `apps/worker/src/index.ts:108–111` rejects API families before dispatching to `handleBrand`. Unmatched paths also return 404 through `apps/worker/src/brand/index.ts:79–80`. No apex route to application, owner or internal APIs was found.
- **Host-header safety:** `normalizeHost` validates host syntax, and `platformContextFor` maps only exact configured platform hosts (`apps/worker/src/host/classify.ts:53–88`). An arbitrary hostile Host cannot reach the brand handler as `MARKETING_APEX`.
- **Asset allow-list:** the only `ASSETS.fetch` call in the brand handler is guarded by `BRAND_ASSETS.has(path)` and constructs `/app` plus that approved path (`apps/worker/src/brand/index.ts:21–55`). Trailing slash normalization does not provide an arbitrary asset-fetch path. Encoded or doubled interior slashes do not become general pass-through routes.
- **Asset headers and CSP:** asset responses preserve the binding’s content type and receive a one-day public cache policy and `nosniff` (`index.ts:49–54`). The brand HTML response itself sets no CSP; therefore the SPA’s CSP must not be assumed to protect the apex. No CSP-induced script-loading failure was evident in the supplied UI results.
- **No cookie-writing logic:** the inspected brand handler and shell do not read session cookies or create `Set-Cookie`. Worker tests assert its absence on all ten HTML pages even when an app cookie is supplied (`brand.test.ts:24–28`).
- **SSR escaping:** legal names, addresses, contact values, branding and application links are escaped at their HTML sinks in `pages.ts` and `seo.ts`. Canonical/OG URLs are escaped. JSON-LD uses `JSON.stringify(...).replace(/</g, "\\u003c")` (`seo.ts:171`). No exploitable request/DB interpolation was found.
- **Inline demo HTML:** the `innerHTML` builders use static courier/service datasets or static option markup, not request or DB values. Receipt and label text use `textContent`. Neither demo contains API/provider request code.
- **Custom Select:** its trigger/listbox/options have labels, roles, expanded/selected state, an active descendant, arrow/Home/End selection, Enter/Space confirmation, Escape handling, focus return after selection, and outside-pointer dismissal (`pages.ts:74–91,150–160`). The supplied UI evidence confirms keyboard selection and trigger focus return at both tested widths.
- **SEO structure:** ten metadata entries, absolute parameter-free canonicals, subpage breadcrumbs, the required JSON-LD graphs, OG metadata and staging `noindex` are implemented in `seo.ts`. Sitemap generation uses all ten entries (`index.ts:68–75`). The supplied `seo-check.txt` reports **0 failures and 0 warnings for all ten pages**.
- **Nine courier brands:** the partner strip contains exactly the nine active brands and omits Ninja (`pages.ts:7–18,175–183`).
- **Home-only vendor loading:** both external hero scripts are deferred and included only in `HOME_SCRIPT`; `index.ts:109` selects that script only for `/`. The IntersectionObserver prevents scene updates/rendering off-screen. This is distinct from the broken user-pause behavior in finding 1.
- **Supplied UI evidence:** `ui-gates-r0.json` records zero horizontal overflow, zero page/console errors, and no broken courier images on the exercised desktop/phone screens. This evidence does not establish pause/reduced-motion correctness or the untested asset cases.
- **Bundle hygiene remains gated:** ignoring vendor bundles for lint does not exempt them from `scripts/ci/bundle-audit.mjs` and `bundle-audit-lib.mjs`, which scan built client assets for source maps and secret-shaped content.

**Verification limitation:** automated tests and the integrated 9/9 gate were not executed during this read-only review; no passing integrated-run artifact was supplied.
